# Моя нумізматична колекція

Статичний сайт-галерея колекції (78 позицій) для GitHub Pages.

## Як опублікувати

1. Створіть на GitHub новий публічний репозиторій (наприклад, `my-collection`).
2. Завантажте в нього вміст цієї папки: `index.html` та папку `images/`.
3. У репозиторії відкрийте **Settings → Pages** → у розділі *Build and deployment* оберіть **Deploy from a branch**, гілка `main`, папка `/ (root)`.
4. За хвилину сайт буде доступний за адресою `https://ВАШ_НІКНЕЙМ.github.io/НАЗВА_РЕПОЗИТОРІЯ/`.

## Структура

- `index.html` – уся галерея (стилі, скрипти й дані всередині файла)
- `images/` – 78 фото аверсів у повній якості

Фото та характеристики – з офіційного інтернет-магазину НБУ, станом на 28.09.2026.
